\section{Platform Selection}

Oracle VirtualBox was selected as the virtualization platform
for the first phase of the project.

Virtualization enables the creation of isolated operating systems
without the need to dedicate a separate computer to each function.

It also allows for administrative
and networking experiments without directly affecting the host system.

\section {Virtual Machine Configuration}

A virtual machine was created for the Ubuntu Desktop system.

The initial configuration includes:

\begin{itemize}
    \item Ubuntu Desktop 24.04 LTS operating system,
    \item 4 virtual processors,
    \item 8 GB of RAM,
    \item a dynamically allocated virtual disk,
    \item a VMSVGA graphics controller,
    \item a first network adapter operating in NAT mode.
\end{itemize}

NAT mode allows the virtual machine to communicate with the Internet,
while restricting direct access to the machine from the host network.
