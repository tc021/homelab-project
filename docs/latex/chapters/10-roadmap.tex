\section{Plan rozwoju}

Projekt będzie realizowany iteracyjnie.

\begin{enumerate}
    \item Foundation -- Virtualization and Linux
    \item Networking
    \item Git and Documentation
    \item Security Foundation
    \item Containerization
    \item Core Infrastructure Services
    \item Databases
    \item Web, File Transfer and Game Services
    \item Monitoring and Observability
    \item Infrastructure as Code and Automation
    \item IoT and Robotics
    \item Data Engineering
    \item Machine Learning and MLOps
    \item Container Orchestration
    \item High Availability
    \item Backup and Disaster Recovery
    \item Chaos Engineering
\end{enumerate}

Każdy etap powinien zakończyć się weryfikacją działania,
aktualizacją dokumentacji oraz zapisaniem zmian w repozytorium.
