\section{Project Gloas}

Celem projektu jest stworzenie własnego "HOMELAB" przeznaczonego do nauki i praktycznego zastosowania 
zagadnień związanych z administracją systemów Linux, sieciami komputerowymi, bazami danych, automatyzacji oraz MAchine Learning.

Projekt jest rozwijany od podstaw, począwszy od przygotowania infrastruktury wirtualnej i systemu operacyjnego, poprzez konfigrację scieci,
aż do uruchamiania usług aplikacyjncyh.

\section{Zakres projketu}

\begin{itemize}
    \item Wirtualizacja systemów operacyjnych;
    \item Adminiastracja systemami Linux;
\end{itemize}

W początkowej fazie projektu wszystkie rozwiązania będę tworzone w środowisku laboratoryjnym. W późniejszych etapach jest planowana ich separacja.
