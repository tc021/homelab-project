\section{Project Objective}

The objective of the project is to design and implement a custom
laboratory environment intended for learning and the practical application of concepts
related to Linux system administration, computer networks, databases,
automation, and machine learning.

The project is being developed from scratch, starting with the preparation of the
virtual infrastructure and operating system, through network configuration, all the way to
the deployment of application services.

One of the project’s objectives is the ability to reproduce the environment and
document architectural decisions and problems encountered during
implementation.

\section{Project Scope}

The planned scope of the project includes, among other things:

\begin{itemize}
    \item operating system virtualization,
    \item Linux system administration,
    \item network design and configuration,
    \item service containerization,
    \item relational and non-relational databases,
    \item communication between services,
    \item infrastructure automation,
    \item monitoring,
    \item IoT devices and automation,
    \item data processing,
    \item machine learning,
    \item deployment of game servers.
\end{itemize}

In the initial phase, all services can operate in a shared
laboratory environment. In later stages, their
segmentation is planned, with particular emphasis on separating publicly
accessible game servers from the administrative infrastructure, databases,
and other services.
