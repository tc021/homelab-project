\section{Functional Requirements}

The environment should support workloads and experiments across several
technical domains.

\subsection{Networking}

The platform should support practical work with:

\begin{itemize}
    \item IPv4 and IPv6 addressing,
    \item routing,
    \item DNS,
    \item DHCP,
    \item NAT,
    \item VLANs,
    \item VPN,
    \item firewalls,
    \item reverse proxies,
    \item network segmentation,
    \item traffic analysis,
    \item IDS/IPS solutions.
\end{itemize}

\subsection{Databases}

The environment should support deployment and administration of different
database systems, including topics such as:

\begin{itemize}
    \item relational databases,
    \item NoSQL databases,
    \item replication,
    \item backup and recovery,
    \item monitoring,
    \item query optimization,
    \item access control,
    \item database security.
\end{itemize}

\subsection{Application Hosting}

The infrastructure should support:

\begin{itemize}
    \item websites,
    \item web applications,
    \item REST APIs,
    \item backend services,
    \item reverse proxying,
    \item TLS termination.
\end{itemize}

\subsection{File Transfer Services}

The environment should provide controlled file transfer capabilities.

Initial implementation may include FTP-compatible services, while secure
alternatives such as SFTP or FTPS should be preferred where appropriate.

\subsection{Game Servers}

The platform should support dedicated game servers.

During the initial laboratory phase, game servers may share infrastructure
with other services. In later stages they should be isolated using dedicated
network segments, firewall rules, and resource limits.

\subsection{Automation and Robotics}

The environment should support integration with:

\begin{itemize}
    \item IoT devices,
    \item microcontrollers,
    \item sensors,
    \item actuators,
    \item robotics platforms,
    \item MQTT-based communication.
\end{itemize}

\subsection{Data Engineering and Machine Learning}

The platform should support a complete data lifecycle:

\begin{center}
Data Sources $\rightarrow$ Ingestion $\rightarrow$ Storage
$\rightarrow$ Processing $\rightarrow$ Machine Learning
$\rightarrow$ Deployment
\end{center}

Future stages should also include MLOps concepts such as model versioning,
deployment automation, monitoring, and retraining.
