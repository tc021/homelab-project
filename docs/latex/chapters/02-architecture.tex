\section{Initial Architecture}

The first component of the environment is a host computer running Windows,
on which Oracle VirtualBox has been installed.

The first virtual machine was set up for learning Linux
and as a development environment.

The initial architecture can be represented as follows:

\begin{lstlisting}[style=terminal]
Windows Host
    |
    +-- VirtualBox
          |
          +-- Ubuntu Desktop
                |
                +-- Linux administration
                +-- Networking
                +-- Development
                +-- Databases
                +-- Automation
                +-- Machine Learning
                +-- Game Servers
\end{lstlisting}

The architecture is intentionally simplified. In subsequent stages of the project,
individual functions will be separated into distinct virtual machines,
containers, and network segments.

\section{Security Assumptions}

The environment is initially treated as a laboratory network.
However, it is not assumed that this architecture will be the final solution.

In particular, game servers, which may be accessible
from the Internet in the future, should be separated from the administrative infrastructure
and data storage services.

The target architecture should allow for division into at least the following segments:

\begin{itemize}
    \item management,
    \item laboratory infrastructure,
    \item databases,
    \item automation and IoT,
    \item game servers.
\end{itemize}
