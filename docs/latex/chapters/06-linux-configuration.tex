\section{Environment Verification}

After creating the base snapshot, system configuration began.

The following commands, among others, were used to identify the system:

\begin{lstlisting}[style=terminal]
hostnamectl
lsb_release -a
uname -r
\end{lstlisting}

These commands allow you to check the host configuration, the
distribution version, and the version of the running Linux kernel, respectively.

The system was then updated using the APT package manager.

\begin{lstlisting}[style=terminal]
sudo apt update
sudo apt upgrade
sudo apt autoremove
\end{lstlisting}

\section{Problem with Shutting Down the System}

During operation, it was observed that executing:

\begin{lstlisting}[style=terminal]
sudo shutdown now
\end{lstlisting}

may be blocked by an active GNOME session.

The system reported an active inhibitor belonging to the
\texttt{gnome-session} process.

The following command was used for diagnostics:

\begin{lstlisting}[style=terminal]
systemd-inhibit --list
\end{lstlisting}
