\section{Initial Network Configuration}

The initial Ubuntu virtual machine uses two network interfaces.

A short interface summary can be obtained using:

\begin{lstlisting}[style=terminal]
ip -br addr
\end{lstlisting}

The first interface is connected to the VirtualBox NAT network and provides
Internet access.

The second interface is connected to the VirtualBox Host-Only network and
is dedicated to laboratory communication.

\section{Network Roles}

The interfaces have different responsibilities:

\begin{description}
    \item[NAT interface] Provides outbound Internet connectivity.
    \item[Host-Only interface] Provides isolated communication between
    the Windows host and virtual machines in the SypIT laboratory.
\end{description}

This separation allows Internet access and internal laboratory traffic
to be managed independently.

\section{Laboratory Network}

The initial laboratory subnet is:

\begin{center}
\texttt{192.168.100.0/24}
\end{center}

At the current stage the network remains intentionally simple.

Future phases will introduce:

\begin{itemize}
    \item dedicated routing,
    \item VLAN segmentation,
    \item firewall-controlled inter-segment communication,
    \item dedicated management networks,
    \item DMZ networks,
    \item game server isolation,
    \item IoT isolation.
\end{itemize}
